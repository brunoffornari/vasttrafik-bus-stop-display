# Using and sharing this project

This project is shared so that you can **use it, copy it and change it for yourself**. It is a personal project, so
it does **not accept pull requests or code contributions**, and only the author can change this repository.

You are free to:

- **Use** it for your own display.
- **Fork it** (make your own copy on GitHub) and change it as you like. The code is under the
  [MIT License](LICENSE) and the 3D case under [CC BY-SA 4.0](case/LICENSE): keep the credit, and share a changed
  case under the same license.

## Problems and questions

You can open an **Issue** if something in the guides does not work for you. There is no promise of an answer or a
fix, and the author may not reply. If you do, please say:

- which board you have, your operating system, and the Arduino IDE and library versions
- what the screen or the Serial Monitor (115200 baud) shows

**Never post your Västtrafik key, your WiFi password or your update password**, in an issue or in a screenshot.
Remove them first.
