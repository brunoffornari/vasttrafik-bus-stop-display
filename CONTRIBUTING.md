# Contributing

Thanks for helping! Small fixes, new ideas and "it didn't work for me" reports are all welcome.

- **Found a problem?** Open an issue. Say which board you have, your operating system, the Arduino IDE and
  library versions, and what the screen or the Serial Monitor (115200 baud) shows.
- **Never post your Västtrafik key, your WiFi password or your update password**, in issues, pull requests or
  screenshots. Remove them first.
- **Pull requests:** keep them small and say what you tested on real hardware. Match the existing code style.
  Do not commit `secrets.h`, firmware files built with it, or anything with keys.
- **Licenses:** by sending a contribution you agree that code is released under the MIT License
  and changes to the 3D case under CC BY-SA 4.0.
